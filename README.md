# PinNote

贴在屏幕右上角的极简便签。打开就能写，关掉还在。

为「只想随手记点东西」而做：没有账号、没有云同步、没有分类树，只有一列便签和几个必要的开关。

## 功能

- **随手记**：顶部输入框，回车即存，不需要点什么保存
- **时间**：每条记录带时间戳（今天显示时分，往前自动带日期）
- **状态**：点左侧圆点循环切换 `待做 → 进行中 → 已完成`
  - 待做：橙色空心圈
  - 进行中：蓝色空心圈 + 实心点
  - 已完成：绿色对勾，文字划线变淡
- **自动排序**：未完成在上（新的在前），已完成的沉到最底
- **删除**：鼠标移到某条上，右侧出现 ×
- **外观**：9 套配色（4 深 5 浅），背景透明度 20%–100% 连续可调，文字始终清晰
- **常驻**：总在最前、开机自启、记住位置和大小
- **收起**：收成 54×54 的小方块，只显示待做数量，点一下展开
- **纯本地**：数据只存本机，不联网

## 使用

| 操作 | 说明 |
| --- | --- |
| 拖动窗口 | 按住顶部空白处拖 |
| 调整大小 | 拖右下角 |
| 记一条 | 输入后按 `回车` |
| 切状态 | 点左侧圆点 |
| 删除一条 | 鼠标移上去，点右侧 `×` |
| 设置面板 | 右上角齿轮 |
| 收起 / 展开 | 右上角 `−` / 点小方块 |
| 关闭面板 | `Esc` |

## 安装

需要 [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)（大多数 Windows 10/11 已自带）。

1. 下载 Release 里的 `PinNote.exe`
2. 放到一个固定目录（比如 `D:\Tools\PinNote\`），双击运行
3. 想要开机自动出现：设置里勾「开机自启」

程序是单实例的，重复双击只会把已有窗口叫到前面。

## 数据在哪

```
%APPDATA%\PinNote\data.json
```

纯文本 JSON，可直接备份或迁移。写入用「临时文件 + 替换」，断电不会写坏；文件损坏时会另存一份 `.corrupt-时间戳` 再重置，不会卡在启动失败。

## 自己编译

```powershell
dotnet publish .\PinNote\PinNote.csproj -c Release -r win-x64 `
  --self-contained false -p:PublishSingleFile=true -o .\publish
```

产出一个几百 KB 的 `PinNote.exe`（依赖已装的 .NET 8 运行时）。
想要完全免运行时的独立版：把 `--self-contained false` 换成 `true`，体积约 70MB。

## 技术选择

WPF / .NET 8，不使用 Electron 或 WebView。冷启动约 0.5 秒，常驻内存约 30–40MB。
